    URL inbox

    Save links to the master archive (tagged, filterable) without hitting TBCC upload until you choose. Queue rows here only when destination is Import queue. Context menu: Add URL to TBCC inbox.

    Dashboard → Master Archive is canonical; the extension mirror is for capture, filters, and hygiene. Archive checked sends selected URLs to the master archive. Import checked runs TBCC download/upload for import-queue rows only.

    Master archive

    Permanent local list of URLs and usernames from inbox, context menu, model search, and copy-media. Backed up in chrome.storage.local (survives most updates). Syncs to the TBCC API when running — view merged history in Dashboard → Archive. 100 entries per page; export for the full list. Copy URLs uses checked rows on this page only.

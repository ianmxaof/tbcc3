Context menu editor

Drag the handle, or use the arrows, to reorder TBCC's right-click menu. Uncheck an item to hide it. Changes apply immediately — no browser restart needed.

Media / page context menu

Right-click on an image, video, link, page, or selected text. Pool / Storage Hub submenus and site-lookup entries are generated live and always appear after this list.

Toolbar icon menu

Right-click the TBCC icon in the toolbar.

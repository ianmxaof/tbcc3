X profile overlay

Thread and timeout limits for the on-page X profile grid and ZIP handoff to the TBCC gallery. Defaults: idle 2 · browse 4 · download 8 · timeout 20s. Idle/browse threads clamp 1–4; download 1–12.

Local stack

The extension can run tbcc/start.ps1 -Full from the side panel or Quick tools: either the small daemon on http://127.0.0.1:8765 (cold start) or POST /internal/launch-full-stack when the API is already running.

Launch from extension

Daemon (recommended): cd tbcc\tools then .\tbcc-launch-daemon.ps1 — leave the window open or add a logon task. In the sidebar Tools panel: Start tray supervisor and Launch full stack (cold).

API base: prefer Tailscale MagicDNS or https://api.<aof-forum-domain> (not bare public IP). Leave blank to try custom → localhost. When TBCC_INTERNAL_API_KEY / TBCC_API_REQUIRE_INTERNAL=1 is on, paste the same key below.

Seed format from scripts/set-extension-island-api.ps1: TBCC_SEED|<apiBase>|<internalKey>. Home Postgres is optional — lean home can push intel to island only.

Custom search URL

Paste the URL from the address bar after you run a manual search on that site (so you get the real query format). Put {username} where the search term goes — often ?q={username} or &query={username}, not a guessed path like /artists/name (many sites 404 on those).

Telegram relay

Send macro search to Telegram

Context menu Send /macrosearch in bot opens your macro search bot (/start ms_…). Set the @username from BotFather for TBCC_MACRO_SEARCH_BOT_TOKEN.

URL inbox (quick view)

Context menu: TBCC: Add URL to inbox or Save all video URLs to inbox (Bunkr-style page scan). Manage pools and import in Gallery → Inbox. New links use your gallery default content pool.

Sources

Username search history

Recent usernames searched by TBCC. Click a username to copy it. Site badge shows where the search was started (Stripchat, Chaturbate, OnlyFans, Instagram, X, …). Remove asks for confirmation.

Master archive

Permanent list of every URL and username captured by TBCC (inbox, copy, model search). Not cleared when you clear the inbox queue. Also open from Gallery → Inbox → Master archive. Export JSON/CSV for off-browser backup.

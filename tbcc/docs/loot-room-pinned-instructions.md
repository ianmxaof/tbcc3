## How a full roll works

Each pull is a weighted roll:

| Piece | Rule |
|--------|------|
| **Rarity tier** | 1–10 (named tiers from Dust → Ascension) |
| **Album size** | Same number as the tier (tier 7 → up to 7 items in that drop) |
| **Modifier slots** | 0–3 bonus modifiers (zip packs, invite links, etc.) |
| **Media** | Pulled from enabled **Loot Room pools** (floor / spotlight / vault bands) |

Higher tiers are rarer. Free pulls show the format; paid keys and VIP unlock the real extras.

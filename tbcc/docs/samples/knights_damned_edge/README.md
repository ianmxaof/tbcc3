## Escalation ladder (how to push darker without breaking the bit)

1. **Wrong relics** — quest objects get more pathetic (single sock → crusted glove → mystery stain on a washcloth).
2. **Queue geometry** — more bodies waiting on locked doors; voyeur POV from behind the line.
3. **Armor vs. flesh** — mail rusted open, hoodies stained, visors cracked so eyes show shame not heroism.
4. **Oracle addiction** — CRT/static scenes multiply; knights can't stop watching for "instructions."
5. **Finality tease** — one panel hints a knight found "completion" off-frame (empty armor heap, abandoned sword, still-warm spot on cardboard).

Keep implication. Explicit acts break the spell and get blocked by models.
